# SVGアイコン設計の参照

小さな表示でも主要モチーフが伝わるように作る。
以下の座標・色・形状は編集可能な例であり、全botに強制する規格ではない。

## 判断基準

- 既存のviewBoxやブランド資産があれば保持する。新規の正方形アイコンでは `0 0 512 512` を作画座標の一例にできる。
- 線幅、余白、文字の大きさは実際の縮小画像で判断する。座標上の線幅だけで視認性を合格にしない。
- 形でも識別でき、必要なコントラストがあることを確認する。文字、装飾、UIの機能アイコンでは適用されるアクセシビリティ基準が異なる。
- 背景、角丸、色数、グラデーションはブランドと表示条件で選ぶ。実際のcropや透過背景で確認する。
- 文字のfont依存がある場合は出力環境での再現性を確かめる。

## モチーフの候補

| 用途 | モチーフの例 |
|---|---|
| 通知 | ベル、拡声器、バッジ |
| 検索・調査 | 虫眼鏡、双眼鏡、レーダー |
| 監視 | フクロウ、目、カメラ |
| 文書・知識 | 本、書類、印章 |
| 鍵・認証 | 鍵穴、盾、鍵 |
| 自動化 | 歯車、ロボット |
| データ | グラフ、DB |
| コミュニケーション | 吹き出し、マイク |

機能と対象を組み合わせると伝わりやすい場合があるが、混雑する場合は主要モチーフを優先する。
既存botと見分けられるかも確認する。

## SVGの例

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 512 512">
  <rect width="512" height="512" rx="96" fill="#1f3a5f"/>
  <g transform="translate(220,220)">
    <line x1="64" y1="64" x2="160" y2="160"
          stroke="#e8a13d" stroke-width="34" stroke-linecap="round"/>
    <circle r="98" fill="#ffffff" stroke="#e8a13d" stroke-width="22"/>
  </g>
</svg>
```

この例の座標と配色は虫眼鏡の構成例。ブランドや用途が異なれば変更する。

## 出力の確認

SVGとPNGの両方を表示し、欠けた形、font置換、背景、透過、crop、縮小時の線と文字を確かめる。
複雑なpathや装飾が原因で識別できなければ、目的を保つ範囲で整理する。
ファイルサイズや色数だけを品質の代わりに測らない。
