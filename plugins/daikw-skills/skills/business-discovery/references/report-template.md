# 事業探索レポートとプロダクトカード

全体レポートが必要な場合の構成。既存資料の比較軸・章立てがあれば継承する。
以下の観点は調査順序や必須の章数を定めるものではない。

## 新規事業スクリーニングレポート: {テーマ}

- 生成日、探索目的、対象市場、自社のアセット、制約
- **Executive Summary**: 推奨候補、優先する理由、成立条件
- **事業スタック分解**: 業界の役割・工程、プレイヤー、参入条件、自社適性。工程数や階層数は実態に合わせる
- **失敗パターン・ガードレール**: 事例、出典、今回にも当てはまる条件、適用しない条件
- **購買トリガーマップ**: 労働力、品質、生産性、安全・規制、知識、事業継続、環境等から実際に支払いにつながる理由を確かめる
- **スコアカード定義**: 採用した比較軸と理由。数値化するなら尺度・重み・閾値の出典
- **ブロードスクリーニング・マトリクス**: 候補、顧客工程、選定/条件付/見送り、根拠、Unknown
- **ウェッジプロダクトカード**: 選定候補の初期製品と導入条件
- **前提再検証・Learning Agenda**: 結論を覆す証拠、次の検証、取得する一次情報

### プロダクトカード

| 項目 | 内容 |
|---|---|
| 顧客・現場のペイン | 対象工程、代替行動、観測事実。想定発言は仮説と明記 |
| 市場の特徴 | 規模の定義、事業所等の母数、地域、規制 |
| Buyer Map | 利用者、推進者、予算保有者、決裁者、導入を止める関係者 |
| 初期プロダクト構成 | 提供範囲、必要なHW/SW/AI、自社・他社の役割 |
| 定量効果 | 指標、導入前後、計算、測定/仮説/不明の区別 |
| 競合と価格帯 | 既存製品、代替行動、比較条件、出典 |
| Unit Economics | 価格、原価、導入費、継続負担、回収の前提 |
| 主要リスク | 技術・販売・規制・運用・資金上の成立条件 |
| 拡張パス | 初期顧客で成立した後に再利用できるものと追加条件 |
